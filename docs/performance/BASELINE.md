Captured before Phase 1 at starting commit `ca26ea97b9b221e36ca768f02186e63e1305bdeb` (`pre-refactor`) on Windows, rustc 1.99.0, cargo 1.99.0. Branch: `refactor/engine-workspace-layout`.

## Workspace test results

`cargo test --locked --workspace` passed on the starting tree. The STUDS golden integration suite passed all four tests: world simulation/settings, Realistic monster, Moody, and Realistic. No golden values were modified.

## Render timings

Release benchmarks, 30 frames per style, 320x180:

- Existing CPU render benchmark (`voxelworks-render-cpu/examples/render_bench.rs`, corridor fixture): baseline 1.483 ms/frame; graded 1.363 ms/frame (-8.1% observed variation).
- STUDS CPU benchmark (`games/studs/examples/realistic_bench.rs`, `Game::new(42)`): Classic 1.348 ms/frame; Moody 1.874 ms/frame; Realistic 8.478 ms/frame.
- GPU offscreen readback benchmark, temporary untracked harness using the same STUDS scene and 320x180 renderer, 3 warmup + 30 measured frames: Realistic 1.114 ms/frame. This includes GPU target readback and should be compared only with later runs of the same method. Windowed surface presentation is a separate faster path and was not timed here.
