# Temporary compatibility shims

The legacy `voxelworks-core` crate temporarily re-exports `engine_math` as `math`, `plugin_voxel::voxel` as `voxel`, `plugin_physics` as `physics`, `engine_app::time` as `time`, and `engine_platform::input` as `input`. The legacy API re-exports `MouseButtons`, `MouseInput`, and `WindowConfig` from `engine_platform`; drawing data and font glyphs from `engine_render`; and aliases the generic `engine_render::FramePlan` for the old scene type. Its renderer trait remains an adapter because its methods expose scene/material types scheduled to move in Phase 7. The legacy scene crate re-exports render data from `plugin_rendering`, retaining the `Scene` alias for `RenderScene`. The legacy CPU renderer crate re-exports the moved CPU renderer, and its fixture golden test remains there to reuse the existing testkit. The legacy platform crate re-exports the moved `cursor`, `keyboard`, `keys`, `timer`, `window`, and CPU `present` modules. The old GPU surface presenter remains until the GPU backend migration. These preserve existing imports while code moves. Phase 9 removes them when the legacy crates are deleted.
