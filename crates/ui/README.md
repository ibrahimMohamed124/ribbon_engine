# ribbon_ui

Immediate-mode game UI with stacking layouts, focus navigation, single-line text input, text
shaping, and a GPU frame pass. Panels measure fit content one frame late. Font assets are Noto Sans
and Noto Sans Arabic under the SIL Open Font License; see `assets/fonts/OFL.txt`.

Not implemented: retained widget trees, flexbox/grid layout, image widgets, color emoji, text
selection/clipboard/undo, multiline editing, accessibility, drag-and-drop, in-world UI, or animated
transitions.
